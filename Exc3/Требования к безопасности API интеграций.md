# Требования к внешним интеграциям

## 1️⃣ Требования к безопасности

1. **Шифрование данных**  
   - Все данные должны передаваться с использованием защищённых протоколов (HTTPS/TLS версии 1.2 или выше).  

2. **Аутентификация и авторизация**  
   - Использовать надёжные механизмы аутентификации для внешних сервисов.  
   - Доступ к API должен предоставляться только авторизованным пользователям с использованием безопасных токенов.

3. **Минимизация передачи данных**  
   - Передавать только необходимые для выполнения операции данные (например, идентификатор пользователя вместо полного профиля).  

4. **Аудит и логирование**  
   - Вести журнал всех операций взаимодействия с внешними системами. Логи должны быть защищены от несанкционированного доступа.  

5. **Ограничение запросов**  
   - Ограничить количество запросов в секунду (Rate Limiting) для защиты от перегрузок и атак.  

---

## 2️⃣ Протоколы аутентификации и авторизации

1. **OAuth 2.0**  
   - Основной протокол для аутентификации и авторизации.  

2. **JWT (JSON Web Tokens)**  
   - Использовать JWT для передачи токенов доступа.  

3. **API Keys**  
   - Применять API-ключи с привязкой к IP-адресам PropDevelopment.  

---

## 3️⃣ Организация взаимодействия между системами

1. **`tenant-core-app`** отправляет запросы к API внешних партнёрских систем (Домофон, Шлагбаум).  
2. **Авторизация** происходит с использованием OAuth 2.0 и токенов доступа.  
3. **Ответы от внешних API** содержат только минимальные данные, необходимые для выполнения операции.  
4. **События и изменения** логируются в системе для последующего аудита и мониторинга.  
5. **Асинхронное взаимодействие через REST API**, чтобы избежать зависаний и долгих операций.
